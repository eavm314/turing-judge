# Turing Judge Playground Documentation

Welcome to the **Turing Judge Playground Documentation**! Here you will find everything you need to know to create, test, and share Finite State Machines (FSM), Pushdown Automata (PDA), and Turing Machines (TM).

This documentation is designed to help you understand how to use both our **Visual Editor** and our **Plain JSON Format**, ensuring you can leverage the full power of the playground whether you prefer dragging and dropping nodes or writing structured code.

## Core Concepts

The playground is structured around a few key features:

<ImagePlaceholder text="Playground Overview - Showing Canvas, Side Menu and Test Pane" />

- **Automaton State Management:** You manage the shape of your automaton which consists of **Nodes** (states) and **Edges** (transitions).
- **The Visual Canvas:** A responsive grid where you can visually place, connect, and organize your automaton's states.
- **The Execution Engine:** Once your automaton is built, the playground provides an engine that evaluates test inputs step-by-step, allowing you to debug transitions visually.
- **Syncing with JSON:** Everything you build in the Visual Canvas is perfectly synchronized with a strict JSON format behind the scenes—and vice versa.
